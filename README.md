# tksignal 📡

Your free tech signal aggregator. One page, zero noise — trending Hacker News stories, GitHub repos, YC startups, and arXiv AI papers, each with an AI-generated "why read this" summary.

**Live site:** https://techikrish.github.io/tksignal/

## Sources

| Section | Source | What it shows |
| :-- | :-- | :-- |
| Hacker News | Algolia HN API | Top stories (points, comments, full-article text fetched for context) |
| GitHub | `github.com/trending?since=daily` scrape | What's hot today, with ⭐ stars and 🔥 stars-today (falls back to Search API if the scrape fails) |
| YC Startups | Algolia YC API | Latest Launch HN + Show HN posts |
| arXiv | arXiv API | Recent AI/ML papers with abstracts |

Reddit (r/artificial, r/LocalLLaMA, r/kubernetes, r/devops) is planned for a future version — its public endpoints rate-limit cloud IPs, so it needs official API credentials.

## AI summaries ✨

Every item gets two AI-generated fields via the **Google Gemini Flash free tier** (1,500 req/day free, no credit card — this project uses ~240/day):

- `aiWhyRead` — one-line "why read this"
- `aiSummary` — a few detailed paragraphs

Summaries render in a shared `src/components/SummaryBlock.astro` card inside each section. Without a `GEMINI_API_KEY`, the fetcher skips summarization and the site builds fine without them.

## How it works

```
scripts/fetch-data.mjs  →  src/data/feed.json  →  Astro static build  →  GitHub Pages
```

`fetch-data.mjs` pulls all four sources, fetches article text / GitHub READMEs for context, calls Gemini (~6.5s pacing between calls), and writes everything to `feed.json`, which the Astro components render at build time. A GitHub Actions workflow re-runs this **every 12 hours** (plus on every push to `main`) so the site stays fresh.

## Run it locally

```sh
npm ci                  # install dependencies (Node >= 22.12.0)

npm run fetch-data      # refresh src/data/feed.json (skips AI summaries without a key)
GEMINI_API_KEY=xxx npm run fetch-data   # full run with AI summaries (~13 min for ~120 items)

npm run dev             # dev server — open the Local URL it prints (if / 404s, try /tksignal)
npm run build           # production build to ./dist/
npm run preview         # preview the built site
```

## Configuration

| Env var | Required? | Default | Purpose |
| :-- | :-- | :-- | :-- |
| `GEMINI_API_KEY` | No | — | Enables AI summaries (free key: https://aistudio.google.com/apikey) |
| `GEMINI_MODEL` | No | `gemini-3.5-flash-lite` | Gemini model to use |
| `GEMINI_RATE_LIMIT_MS` | No | `6500` | Delay between Gemini calls (stays under free-tier RPM) |
| `GITHUB_TOKEN` | No (auto in CI) | — | Higher GitHub API limits for README fetches |

For the live site, `GEMINI_API_KEY` is stored as a GitHub Actions repository secret (Settings → Secrets and variables → Actions), and Pages is served with Source: **GitHub Actions** — see `.github/workflows/deploy.yml`.
